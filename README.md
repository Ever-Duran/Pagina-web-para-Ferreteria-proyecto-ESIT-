# Página-web-para-Ferreter-a-proyecto-ESIT-
Sitio web de Ferretería Alex con catálogo de productos, integración con ostgreSQL y asistente virtual mediante Gemini AI.


Modernización y Autonomía Digital: Proyecto Tecasis s.a.s. de c.v.

Este repositorio documenta el desarrollo integral del ecosistema web para Ferretería Alex, realizado por Ever Daniel Durán Hernández como proyecto de servicio social para el TSU en Desarrollo de Software en Código Abierto de la Escuela Superior de Innovación y Tecnología (ESIT).

🎯 Objetivo del Proyecto Crear una infraestructura web dinámica que promueva la digitalizacíon de Ferretería Alex y automatice la atención al cliente.

🛠️ Stack Tecnológico Core: NodeJS y PostgreSQL. Frontend: HTML5, CSS3, JavaScript (AJAX/Fetch). Servidor: Linux, Render, SSL.
